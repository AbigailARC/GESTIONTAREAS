Breve explicación del código...
app.listen(port, () => { ... });: Inicia el servidor y lo hace escuchar en el puerto especificado. La funciPLICACION DE CODIO PARA EL LOCALL 3000
const express = require('express');: Importa la función express del módulo instalado.
const app = express();: Crea una instancia de la aplicación Express. Esta instancia es la que usarás para definir rutas, middleware, etc.
const port = 3000;: Define la variable port con el número del puerto en el que quieres que tu servidor escuche las conexiones entrantes.
app.get('/', (req, res) => { ... });: Define una ruta para las solicitudes HTTP GET a la raíz del servidor (/).
req (request): Objeto que contiene información sobre la solicitud del cliente.
res (response): Objeto que se utiliza para enviar una respuesta al cliente.
res.send('¡Hola desde Express!');: Envía la cadena de texto "¡Hola desde Express!" como respuesta al cón de callback se ejecuta una vez que el servidor comienza a escuchar, y en este caso, muestra un mensaje en la consola indicando que el servidor está en funcionamiento
